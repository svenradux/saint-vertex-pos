# Project

Vertex POS is the local browser-based Saint Vertex product, using the pinned NexoPOS 6.2.4 core (488573a38503940031a447ac2e5850ff76ca2047). The application is not a from-scratch POS. Intended use is Windows localhost/self-hosted; Indonesian, IDR and Asia/Jakarta are supported store settings. No new tax rules, paid modules or cloud dependencies were introduced.

This source snapshot was selected on 2026-10-22 from the current working application, including uncommitted changes and current generated assets. The existing detached upstream Git history was not imported. Operational state, private backups and credentials remain external. New development uses separate databases and newly generated keys/passwords.
